# Бот-фільтр каналу @chyste_nebo

Особистий Telegram-бот: слухає [@chyste_nebo](https://t.me/chyste_nebo) і надсилає в групи пости, де є ключові слова. У кожної групи свій список.

Bot API не вміє читати чужий канал, тому в одному процесі працюють два клієнти: **teleproto** (ваш акаунт читає канал) і **grammY** (бот для команд і алертів).

## Вимоги

- Node.js 22+
- бот від [@BotFather](https://t.me/BotFather)
- `api_id` і `api_hash` з [my.telegram.org](https://my.telegram.org)
- ваш числовий Telegram user id (наприклад через [@userinfobot](https://t.me/userinfobot))

## Запуск

```bash
npm install
cp .env.example .env
```

Заповніть `.env`:

```
BOT_TOKEN=...
TELEGRAM_API_ID=...
TELEGRAM_API_HASH=...
OWNER_ID=...
CHANNEL=@chyste_nebo
```

```bash
npm start
```

Перший запуск запитає телефон і код підтвердження. Сесія збережеться в `data/session`.

У Telegram:

1. Напишіть боту `/start`
2. Створіть групу (наприклад «сади»), додайте бота, дайте право писати
3. У групі: `/setgroup`, далі `/add Буча`
4. З привату власник: `/add сади Ірпінь` — слово лише для цієї групи
5. `/groups` і `/status` — список чатів і стан

При старті бот реєструє меню команд. У приваті або в групі натисніть **/** біля поля вводу — з’явиться список. Якщо меню не оновилось, закрийте чат і відкрийте знову.

## Команди

У групі `/add Буча` змінює список **цього** чату (будь-хто з учасників).
У приваті з ботом — лише власник (`OWNER_ID`), і треба назва групи: `/add сади Буча`.
`/setgroup` у групі — лише власник (реєструє чат, щоб ним можна було керувати з DM).

| Команда | У групі | У приваті |
| --- | --- | --- |
| `/add` | `/add Буча` | `/add сади Буча` |
| `/remove` | `/remove Буча` | `/remove сади Буча` |
| `/list` | `/list` | `/list сади` |
| `/pause` `/resume` | цей чат | `/pause сади` |
| `/status` | цей чат | усі групи або `/status сади` |
| `/groups` | — | список груп |
| `/setgroup` | зареєструвати цей чат | інструкція |

Пошук — без урахування регістру, з простою основою слова (`Буча` знайде `Бучі`, `На Бучу` і також `Бучач`).
