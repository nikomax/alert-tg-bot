# Бот-фільтр каналу @chyste_nebo

Особистий Telegram-бот: слухає [@chyste_nebo](https://t.me/chyste_nebo) і надсилає в обрану групу лише пости, де є ваші ключові слова.

Bot API не вміє читати чужий канал, тому в одному процесі працюють два клієнти: **teleproto** (ваш акаунт читає канал) і **grammY** (бот для команд і алертів).

## Вимоги

- Node.js 22+
- бот від [@BotFather](https://t.me/BotFather)
- `api_id` і `api_hash` з [my.telegram.org](https://my.telegram.org)
- ваш числовий Telegram user id (наприклад через [@userinfobot](https://t.me/userinfobot))

## Запуск

```bash
npm install
cp .env.example .env
```

Заповніть `.env`:

```
BOT_TOKEN=...
TELEGRAM_API_ID=...
TELEGRAM_API_HASH=...
OWNER_ID=...
CHANNEL=@chyste_nebo
```

```bash
npm start
```

Перший запуск запитає телефон і код підтвердження. Сесія збережеться в `data/session`.

У Telegram:

1. Напишіть боту `/start`
2. Створіть групу, додайте бота, дайте право писати
3. У групі: `/setgroup`
4. У групі будь-хто: `/add Буча` (і інші ключі)
5. Перевірте `/status` — MTProto онлайн, група прив’язана, ключі > 0

При старті бот реєструє меню команд. У приваті або в групі натисніть **/** біля поля вводу — з’явиться список. `/add` і `/remove` після вибору треба дописати слово. Якщо меню не оновилось, закрийте чат і відкрийте знову.

## Команди

У групі всі учасники можуть `/add`, `/remove`, `/list`.
У приваті з ботом — лише власник (`OWNER_ID`): ті самі команди плюс `/pause`, `/resume`, `/status`.
`/setgroup` у групі — лише власник.

| Команда | Дія |
| --- | --- |
| `/add <слово>` | додати ключ |
| `/remove <слово>` | видалити ключ |
| `/list` | показати ключі |
| `/pause` / `/resume` | зупинити / увімкнути алерти |
| `/status` | стан |
| `/setgroup` | прив’язати групу (писати в групі) |

Пошук — без урахування регістру, з простою основою слова (`Буча` знайде `Бучі`, `На Бучу` і також `Бучач`).
